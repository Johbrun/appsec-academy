# Dépôt Novafact (fixture du lab)

Ce dossier imite le dépôt de l'application Novafact : workflows d'intégration
continue, configuration npm, lockfile, CODEOWNERS. **Tous ces fichiers sont
volontairement défectueux.**

Ce n'est pas un vrai dépôt : rien ici n'est exécuté, aucun workflow ne tourne,
et les jetons qu'on y trouve sont inertes et inventés. Les fichiers servent de
support aux challenges du module M14 — on les audite et on les corrige, et
`npm run verify` vérifie la correction.

Ne pas copier ces fichiers dans un vrai projet.
