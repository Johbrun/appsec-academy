## Étape 7 : vulnérabilités avancées

Ton livrable : pour une sélection des sujets du module 9, le **point d’exposition** dans Novafact, la **cause racine** et la **correction**, avec un test ou une règle quand c’est possible. On reste défensif : on décrit le mécanisme et la parade, pas le pas-à-pas d’exploitation.

## Sélectionner les sujets pertinents

Tous les sujets de M9 ne concernent pas Novafact au même degré. Choisis-en quatre ou cinq parmi les plus exposés :

| Sujet (M9) | Où, dans Novafact | Cause racine | Correction |
| --- | --- | --- | --- |
| Prototype pollution | Fusion d’objets de configuration, corps JSON | Clé `__proto__` atteinte par une fusion récursive | Schéma strict (zod), refus de `__proto__`/`constructor`, `Object.create(null)` |
| Désynchronisation de requêtes | Chaîne CloudFront → ALB → Node | Interprétations divergentes de la longueur/du chunking | Aligner les modes, rejeter l’ambigu, mise à jour des composants |
| Parser differential (SAML/XML) | SSO des grands comptes | Vérifier une représentation, en utiliser une autre | N’extraire que l’élément signé, bibliothèque à jour |
| SSRF | Import de logo par URL, assistant IA | URL contrôlée atteignant le réseau interne / IMDS | Allowlist, résolution + filtrage d’IP, IMDSv2 |
| Injection côté ORM | Filtres Prisma/Mongo construits dynamiquement | Opérateurs ou champs contrôlés par l’entrée | Validation stricte, pas de `$queryRawUnsafe`, `sanitizeFilter` |

## Traiter un sujet de bout en bout

Pour chaque sujet retenu, produis la même fiche courte. Exemple pour la prototype pollution, qui est aussi le premier maillon du boss final (jeu Red vs Blue) :

<Code file="apps/api/src/settings/merge.ts" hl="2,3">

```ts
const SettingsPatch = z.object({           // schéma strict : seules ces clés passent
  locale: z.enum(['fr', 'en']).optional(),
  invoicePrefix: z.string().max(8).optional(),
}).strict();

export function applySettings(current: Settings, body: unknown): Settings {
  const patch = SettingsPatch.parse(body);  // rejette __proto__ et toute clé inconnue
  return { ...current, ...patch };
}
```
